H²EPR-Bench

An evidence-traceable benchmark for reconstructing hierarchical heterogeneous event-process graphs from fixed evidence contexts.

H²EPR-Bench evaluates whether language models can reconstruct structured event processes, including stages, actors, temporal relations, actions, outcomes, and evidence links, from the same fixed evidence provided to every system.

Paper forthcoming Public Dataset Request Gold Access Launch Explorer
Official scoring uses the gated Gold companion. Public FinalCascade and Gantt artifacts are released for inspection and reuse, but they are not Gold references and should not be treated as scoring targets.

Release model

Public inspection artifacts, gated scoring references

H²EPR-Bench separates public exploration from official scoring. This boundary is part of the benchmark design, not a file-management detail.

Task

Fixed-evidence event-process graph reconstruction

Input

Each system receives the same event descriptor and fixed public evidence context.

Output

The system reconstructs a hierarchical heterogeneous Event-Process Graph with stages, episodes, actors, actions, relations, temporal anchors, and evidence links.

Evaluation

Graph matching compares reconstructions with gated Gold references across structural fidelity, temporal consistency, action-result logic, and evidence traceability.
