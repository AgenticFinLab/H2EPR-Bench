# Website asset provenance

The static website keeps release-safe figures and aggregate result tables. It
does not contain reference EPG JSON, frozen evidence text, raw model outputs,
provider traces, or internal construction logs.

## Stable project visuals

The hero, background, use-case, release-boundary, and Explorer images preserve
the established H²EPR-Bench public presentation. They are intentionally not
regenerated by a routine Unified-3000 data refresh.

## Unified-3000 visuals

`scripts/build_unified3000_site_release.py` deterministically projects the
approved public aggregate benchmark/result inputs into:

| Website files | Public role |
| --- | --- |
| `assets/summary/dataset-summary-panel.png` | Unified-3000 benchmark totals, distributions, and release structure |
| `assets/charts/*.png` | Public domain, category, and stage distributions |
| `assets/diagnostics/*.png` | Aggregate and event-level reconstruction diagnostics |
| `data/unified3000_21model_main_results.json` | Website projection of the 21-system aggregate results |
| `data/unified3000_21model_diagnostics.json` | Public diagnostic projection with output-failure and token metadata |

The builder requires an explicit approved source root; local source paths are
never written to a public asset or manifest.

## Representative event timelines

The six displayed `H2EPR-*_draft_gantt.png` files visualize public
FinMycelium-generated Draft EPGs. They are not reference EPGs or official
scoring targets.
