## 第一张图：EPG（Event-Process Graph）总览

多来源的固定证据先被组织成有层级、且可以证据追溯追溯的 EPG，然后这个 EPG 既可以用于检验模型是否真正理解了事件（给定模型一个重构任务并打分），也可以成为后续分析、预测和模拟的基础。



图的最左侧是 Fixed Evidence。用新闻、公开公告、报告和监管材料四种来源 表示EPG的FixedEvidence来源是 多种公开材料，这些材料共同构成同一个固定的事件证据包。



中间则展示一个抽象的 Event-Process Graph 结构。它从宏观的 Stage 开始，再进入 Stage 内部的 Episode，最后展开到微观语义图层。微观语义图层 表示参与者是谁、采取了什么行动、产生了什么结果，以及这些元素之间存在哪些有方向、有类型的关系。下方的 Evidence Suppor 层与上方的图组件相连，表示图中的节点和关系能够回到具体证据中找到支持。证据既可以支持某个参与者、行动或结果，也可以支持一条时间、因果或机制关系。  整个子图表示EPG是一个Evidence-traceable的层次化异构事件过程图。



右侧则展示 EPG 可以发挥作用的三个方向（EPG事件形式的用处）。Reconstruction 图表示 将输出 EPG 作为大模型的任务形式，并对重构结果进行评价，能够评测大模型的事件理解能力； Analysis 表示 EPG 这一事件表示形式支持我们可以从多个角度研究事件；Prediction / Simulation 则表示，从已经观察到的事件过程出发，可以继续推测后续发展，或者在不同条件下探索多种可能的未来。





## 第二张图：为什么需要 EPG

面对同一个复杂事件，叙事摘要、顺序时间线和 Event-Process Graph 各自的结构，以及分别能够保留什么信息，突出EPG的优势。



左上角的 Narrative Summary 表示，几份相关材料可以被整理成一段连贯、易读的叙事。 摘要能够把事件背景、发展过程和最终结果综合起来，也能够在文字中提到参与者、行动和结果。它的优势是自然、流畅，适合读者快速了解发生了什么。但这些内容仍然埋在连续文字里：事件包含哪些层级、某个行动与哪个结果相连、不同事实之间是什么类型的关系，以及某一句判断具体由哪份材料支持，无法被显式表示出来。



左下角的 Sequential Timeline 能够显示表达事件的时间顺序。读者可以很快看到事件从开始、经过若干里程碑到结束的大致过程，因此它适合回答“先发生什么、后发生什么”。但时间线仍然比较扁平。它不容易同时表达不同参与者做了什么、多个行动如何交叉、一个结果由哪些机制产生，也没有吧具体证据准确连接到某个节点或某条关系上。



右侧的 Event-Process Graph 占比较大的篇幅，具体展示EPG的结构。最上方先展示事件的 Stage chain，并选中 Stage 2；Stage 2 内部又包含多个 Episode，其中 Episode 2 被选中并向下展开。把 Event → Stage → Episode 的层级表示出来。

中间的 Micro-level Semantic Graph 继续展开选中的 Episode。参与者、行动和结果使用不同形状表示，普通黑色箭头表示过程中的连接，带标签的紫色关系则进一步区分因果、时间和机制等不同含义。 表示事件在EPG中如何组成一个有方向、有结构的过程。



最下方的 Evidence Graph 表示多来源证据与事件结构之间的对应关系。新闻、公开公告、公共记录和报告等多源事件通过虚线从具体来源片段连接到上方的参与者、行动、结果或关系，表达证据支持可以落到具体的图元素上，也可以支持一条关系。



这张图表达的是：摘要擅长形成流畅的整体叙述，时间线擅长保留先后顺序，而 EPG 则通过层次化异构图的方式进把层级、时间顺序、参与者、行动、结果、关系和证据支持同时显式保留下来。



## 第三张图：小图-Reconstruction

在给定同一组固定证据的情况下，让 ai系统完成事件重构任务，并以 Event-Process Graph 的形式输出，- Candidate EPG- 。我们另外有一份独立构建的 Reference EPG，作为评测时的参考答案。通过比较 Candidate EPG 与 Reference EPG，可以从结构、时间、因果和证据支持等多个维度进行打分，进而评估ai系统对复杂事件过程的重构能力。



## 第四张图：小图-analysis

当事件已经被表示成结构化 EPG 之后，我们不再只是能阅读一段文字，而是可以以图的形式从多个角度研究事件过程。这里表达三类互相区别的分析视角：一是观察 Stage 和 Episode 怎样组织成完整过程，事件的时序发展和层级关系；二是研究因果、机制和 action–outcome 等关系；三是可以比较多个事件的EPG结构，寻找相似的路径、转折、角色和过程模式。



## 第五张图：小图-Prediction / Simulation

EPG 不只描述已经发生的过程，还可以为研究事件接下来怎样发展提供数据基础。
Prediction 探究在当前信息下，下一步较可能出现什么 Episode、参与者行动、结果。
Simulation 探究在不同条件、干预或参与者行为下，用 agent取代事件参与者，事件可能沿哪些不同路径继续演化。



## 第六张图：长期愿景-Societal World Model

表达EPG形式能够支持的一个更长期的方向：当我们不再只看某一个孤立事件，而是把大量真实事件都表示成结构化、可追溯的 Event-Process Graph，并进一步把这些事件连接起来，就有可能逐步形成一个描述社会运行过程的 World Model ， 突出项目的潜力和长期愿景。。



现实中的事件并不是彼此独立的。一个事件产生的结果，往往会改变市场环境、政策条件、公众预期或参与者的状态，并成为后续事件发生的背景。例如，一项监管决定可能改变企业行为，企业的应对又可能影响市场和投资者，市场变化还可能进一步引发新的政策讨论。不同事件之间会通过共同的参与者、时间关系、因果关系、资源流动和行动结果不断连接，形成持续演化的社会过程。



EPG 为这种连接提供了比较合适的基础。每个 EPG 都记录了一个事件内部的 Stage、Episode、参与者、行动、结果、关系和证据支持。当多个 EPG 被连接起来时，我们不仅能够知道“发生了哪些事件”，还可以继续追踪：一个事件的结果怎样成为另一个事件的条件，同一个参与者怎样在不同事件中持续行动，不同事件之间存在怎样的因果传播、反馈循环和长期影响。



用一个逐步扩展的形式表述以上信息，：首先是多个由真实证据支撑的独立 Event-Process Graph；随后，这些图通过共享参与者、前因后果和跨事件关系连接成更大的过程网络；最后，这个不断演化的网络成为 Societal World Model 的结构基础，表达社会状态怎样在一系列相互关联的事件中持续变化。在这个基础上，World Model 可以进一步支持更丰富的研究。我们可以观察某类社会或市场过程通常怎样发展，分析局部事件如何向更大范围传播，也可以从当前状态出发，研究接下来可能出现哪些事件和反馈。进一步地，还可以改变某些条件，例如政策选择、外部冲击或参与者行为，比较不同条件下社会过程可能沿哪些路径演化。
