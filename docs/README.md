# H2EPR-Bench documentation

This directory contains stable guidance for the public H2EPR-Bench repository.
The repository README remains the main entry point; the documents here explain
resource identities, release boundaries, publication steps, and current visual
communication briefs.

## Documents

| Document | Purpose |
| --- | --- |
| [Repository identity](repository-identity.md) | Defines the roles and source-of-truth boundaries of the GitHub repository, public Dataset, gated Reference EPGs, Explorer, and FinMycelium. |
| [Public resource links](public-resource-links.md) | Defines canonical reader-facing labels, URLs, button behavior, and public-access boundaries. |
| [Public release process](release-process.md) | Describes review, validation, publication, rollback, and release-receipt requirements. |
| [Figure descriptions (Chinese)](图片描述.md) | Records the intended messages of the current website figures and use-case visuals. |

Time-bound implementation plans, wording drafts, and local release-candidate
receipts belong in issues, pull requests, or local release records rather than
the stable public documentation set. Their earlier versions remain available
through Git history.
